# SmoothFlow Android

تطبيق أندرويد لمعالجة الفيديو محلياً ورفع معدل الإطارات باستخدام RIFE (NCNN)، وليس بتكرار الإطارات أو تعديل بيانات FPS فقط.

## الحالة

هذا المستودع يبني نسخة تجريبية تستهدف أجهزة Android 8.0+ بمعمارية ARM64. محرك RIFE v2.3 يُحمّل محلياً أول مرة (حوالي 54 MB)، ثم تتم عملية الاستيفاء على الهاتف. الصوت الأصلي يُنسخ إلى ملف MP4 الناتج.

## ملاحظات التوافق

- معدلات الإدخال المدعومة في هذا الإصدار: 25→50 FPS أو 30→60 FPS.
- لتقليل احتمال نفاد الذاكرة على الهواتف المتوسطة، تُخفّض أبعاد الإطارات إلى حد أقصى 720p أثناء المعالجة.
- يُفضّل بدء التجربة بمقطع قصير (5–10 ثوانٍ). أداء RIFE يتفاوت كثيراً حسب المعالج/دعم Vulkan.
- ملف APK يُبنى في GitHub Actions ويُنشر في Releases عند نجاح البناء. البناء لا يثبت أن الأداء جُرّب على هاتف فعلي.

## المكونات

- Android/Kotlin، MediaMetadataRetriever، MediaCodec وMediaMuxer.
- RIFE v2.3 مع NCNN عبر NDK/JNI.
- ملفات النموذج تُنزّل من مستودع nihui/rife-ncnn-vulkan وتُتحقق باستخدام Git blob SHA-1.

## Build

GitHub Actions يحمّل مصدر RIFE وsubmodules ويُعدّل target الأصلي إلى مكتبة static حتى يمكن ربطه بجسر JNI، ثم ينفّذ `gradle assembleDebug`.
