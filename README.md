# SmoothFlow Android

تطبيق أندرويد لمعالجة الفيديو محلياً ورفع معدل الإطارات باستخدام RIFE (NCNN)، وليس بتكرار الإطارات أو تعديل بيانات FPS فقط.

## الحالة

نسخة تجريبية تستهدف Android 8.0+ بمعمارية ARM64. محرك RIFE v2.3 يُحمّل محلياً أول مرة (حوالي 54 MB)، وبعدها تتم المعالجة على الهاتف. الصوت الأصلي يُنسخ إلى ملف MP4 الناتج.

## ملاحظات التوافق

- معدلات الإدخال المدعومة حالياً: 25→50 FPS أو 30→60 FPS.
- أبعاد الإطارات محدودة بحد أقصى 1280 بكسل على الضلع الأطول لتقليل ضغط الذاكرة.
- يُفضّل بدء التجربة بمقطع قصير (5–10 ثوانٍ). أداء RIFE يتفاوت حسب المعالج ودعم Vulkan.
- ملف APK يُبنى في GitHub Actions ويُنشر في Releases عند نجاح البناء. نجاح CI لا يعني اختبار الأداء على هاتف فعلي.

## Build

GitHub Actions يحمّل مصدر RIFE المثبت على commit محدد وsubmodules، ثم يربط RIFE عبر JNI ويبني APK.
